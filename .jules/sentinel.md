## 2024-05-15 - Prevent Network Stream Credential Predictability
**Vulnerability:** The proxy credential generation in `src/netbase.cpp` for SOCKS5 Tor stream isolation was using `insecure_rand()`. This meant the generated random usernames and passwords for stream isolation could be predicted, potentially compromising the Tor identity isolation guarantees by linking separate streams to the same predictable credentials.
**Learning:** `insecure_rand()` is an intentionally weak (but fast) PRNG (MWC RNG of George Marsaglia). Its output is predictable and should never be used for security or cryptographic boundaries, including network credentials or stream isolation IDs.
**Prevention:** Always use a Cryptographically Secure Pseudo-Random Number Generator (CSPRNG) such as `GetRandHash()` or `GetRand()` when generating unpredictable identifiers like proxy authentication credentials or temporary tokens.
