## 2024-05-24 - Optimization in ProcessMessage loop
**Learning:** Found an inefficient `BOOST_FOREACH` loop that iterated over a constant `std::vector<std::string>` to find a specific message string inside `ProcessMessage`. The original loop performed a value copy of each string element. In high-throughput network processing code (`src/main.cpp:ProcessMessage`), avoiding value copies on each iteration is important for latency and CPU overhead.
**Action:** Replace `BOOST_FOREACH(const std::string msg, allMessages)` with `bool found = std::find(allMessages.begin(), allMessages.end(), strCommand) != allMessages.end();` to leverage `<algorithm>` efficiency without redundant string copies, or at minimum use `const auto&` range-based loops to prevent copying complex types in performance critical code paths.
